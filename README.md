# Convie记账本

随手记，轻松管 — 一款跨平台个人记账工具

## 功能特点

- **支出记录**：按日期、分类记录每笔支出，支持金额、备注
- **分类管理**：9个一级分类 + 41个二级分类，支持自定义增删改
- **数据概览**：月度统计卡片、分类占比饼图、每日趋势柱状图
- **统计报表**：年度支出趋势、分类支出占比、关键词分析
- **数据导出**：一键导出支出记录为 CSV 文件
- **本地存储**：所有数据存储在本地，无需联网，保护隐私

## 安装说明

### Windows

1. 下载 `Convie记账本 Setup.exe` 安装包
2. 双击安装，选择安装路径
3. 安装完成后，桌面会出现快捷方式

### macOS

1. 下载 `Convie记账本.dmg` 文件
2. 双击打开，将应用拖入 Applications 文件夹
3. 首次打开时，如果提示"无法验证开发者"，请前往「系统设置 → 隐私与安全性」中点击「仍要打开」

## 使用说明

### 记录支出

1. 点击左侧「支出记录」
2. 点击右上角「新增支出」按钮
3. 填写金额、选择日期、选择分类（先选一级，再选二级）
4. 可选填写备注信息
5. 点击「保存」

### 查看概览

- 点击左侧「概览」查看当月支出统计
- 顶部卡片显示：总支出、笔数、笔均支出、最大支出类别
- 左下显示分类支出占比饼图
- 右下显示每日支出趋势柱状图
- 底部显示分类支出排行

### 查看统计

- 点击左侧「统计报表」查看年度数据
- 顶部卡片显示：全年总支出、总笔数、笔均支出、最高月份
- 左侧显示月度支出趋势折线图
- 右侧显示分类支出占比饼图

### 管理分类

- 点击左侧「设置」
- 点击「新增一级分类」创建新的大类
- 点击一级分类旁的 `+` 按钮添加子分类
- 点击编辑按钮修改分类名称
- 点击删除按钮删除自定义分类（系统预设不可删除）

### 导出数据

- 在「支出记录」页面，点击「导出 CSV」按钮
- 浏览器会自动下载包含所有支出记录的 CSV 文件
- 可用 Excel 或 WPS 打开查看

## 技术栈

- 桌面框架：Electron
- 前端：React 18 + TypeScript
- UI 组件：Ant Design 5
- 图表：ECharts 5
- 数据库：SQLite（sql.js）
- 状态管理：Zustand
- 构建工具：Vite + electron-vite

## 数据存储

数据文件存储在：

- Windows: `%APPDATA%/ConvieLedger/convie_ledger.db`
- macOS: `~/Library/Application Support/ConvieLedger/convie_ledger.db`
